# Telegram Mega Multiplayer Game Bot

A complete, production-ready Telegram bot with 13 multiplayer games, shared player accounts, global economy, and multi-language support.

## Features

### 13 Games
1. ⚔️ Mafia RPG - Complete crime empire simulator
2. 🌌 Space Empire - Galaxy exploration and conquest
3. 🧟 Zombie Apocalypse - Survival horror
4. 🏴‍☠️ Pirate Empire - Naval adventures
5. 🧪 Mutation Lab - Creature breeding and evolution
6. 👻 Haunted Telegram - Paranormal investigation
7. 🧠 Mind Wars - Brain games and challenges
8. 🏙️ Build Your City - City management
9. 🕵️ Spy Network - Espionage and intelligence
10. 🐉 Dragon Kingdom - Dragon training and battles
11. 🎴 Collectible Card Battle - Card game PvP
12. 🔎 Crime Detective - Murder mystery solving
13. 🏎️ Street Racing Empire - Racing and upgrades

### Core Features
- Shared player accounts across all games
- Global economy with coins, gems, XP, and respect
- Inventory system for items and collectibles
- Achievement and title system
- Trading system with two-step confirmation
- Leaderboards with multiple categories
- Seasonal content and events
- Gang system with gang wars
- Group worlds for Telegram chats
- Admin panel for moderation
- Anti-cheat and security measures
- Multi-language support (23 languages)
